# AI file translation

This document translation Gradio app is created for automatic translation of documents from - and into - a language of choice. Documents can be of type .pdf, .docx or .txt. Output is in the form of a document, with file extension of choice. Again .pdf, .docx or .txt. During the process of translation, the format and style of the documents are preserved as much as possible.

Currently, translation is executed by an OpenAI LLM of choice, depending on the settings. The OpenAI model of choice must be a model that is deployed on an Azure platform.
